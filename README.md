# 人民观点·公考素材积累

自动采集人民网观点频道文章，通过 AI 提取结构化分析，生成可离线阅读的 HTML 页面，适用于公考面试备考。

## 项目结构

```
人民网自动总结/
├── main.py                    # 入口脚本（调用 scripts/main.py）
├── README.md                  # 项目说明
├── scripts/                   # 核心脚本
│   ├── config.py              # 配置文件（API、爬虫、路径等）
│   ├── main.py                # 主流程编排
│   ├── scraper.py             # 爬虫模块（采集文章列表和正文）
│   ├── analyzer.py            # AI分析模块（调用Mimo API提取结构化总结）
│   └── html_generator.py      # HTML生成模块（PC多页版 + 按周分页版）
├── data/                      # 数据文件
│   ├── articles.json          # 已采集的文章列表（含正文）
│   ├── summaries.json         # AI分析结果
│   └── progress.json          # 爬虫断点续传进度
├── output/                    # HTML输出（按版本归档）
│   ├── 20260601 v1.0/         # v1.0 版本
│   └── 20260614 v2.0/         # v2.0 版本
└── logs/                      # 运行日志
    └── scraper.log
```

## 使用方法

在项目根目录下执行：

```bash
# 查看当前进度
python main.py status

# 一键增量更新（采集新文章 + 抓取正文 + AI分析 + 生成HTML）
python main.py update

# 分步执行
python main.py collect          # 1. 采集文章列表
python main.py fetch            # 2. 抓取文章正文
python main.py analyze          # 3. AI分析
python main.py html             # 4. 生成HTML

# 全流程（从零开始）
python main.py run

# 测试模式（取前N篇运行全流程）
python main.py test 10
```

## 输出说明

每次更新后，将 output 根目录的文件归档到版本文件夹：

```
output/
├── 20260601 v1.0/                          # v1.0 归档
├── 20260614 v2.0/                          # v2.0 归档
│   ├── week_2025-W23.html ~ week_2026-W24.html  # 按周分页版（53个）
│   └── 人民观点_公考素材积累 20260613.html       # 单文件内部分页版
└── ...
```

### 两种 HTML 版本

| 版本 | 文件 | 适用场景 |
|------|------|----------|
| 按周分页版 | `week_YYYY-Www.html` | 每周独立文件，适合分发单周内容 |
| 单文件内部分页版 | `人民观点_公考素材积累 YYYYMMDD.html` | **推荐**，一个文件包含全部文章，内部翻页，适合手机阅读和分享 |

### 移动端阅读

**单文件版（推荐）**
- 用手机浏览器直接打开即可阅读
- 顶栏翻页控件 + 底部完整页码导航 + 页码输入跳转
- 左上角 ☰ 菜单展开目录，支持搜索和筛选
- 左右滑动翻页，键盘←→翻页
- 右下角 ▲▼ 按钮快速定位顶部/底部

**按周分页版**
- 顶部下拉菜单跳转任意一周
- 单个文件体积小（20-150KB），适合微信/小红书发送

## 配置说明

编辑 `scripts/config.py`：

- **AI_API_KEY**：Mimo API 密钥（兼容 Anthropic 协议）
- **CATEGORIES**：采集的人民网栏目列表及最大翻页数
- **REQUEST_DELAY**：请求间隔（秒），避免过快被封
- **HTML_BATCH_SIZE**：PC版每页文章数（默认50）

## 版本命名规则

采用 `YYYYMMDD vX.X` 格式，例如：
- `20260601 v1.0` — 首次生成，652篇文章
- `20260614 v2.0` — 数据更新至6/13，UI改进，新增按周分页
